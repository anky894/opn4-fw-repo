Fastboot firmware update packages for OnePlus Nord 4

For both CPH2661 and CPH2663

latest release: https://github.com/anky894/opn4-fw-repo/releases/latest

Just extract the fastboot_firmware.zip and run,
`install_images.sh` (linux) or
`install_images.bat` (windows)
on bootloader mode.

**NOTE**: Use only with custom roms.
